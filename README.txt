# Heet Birthday Surprise ❤️

A romantic, responsive birthday website made for Heet by Devanshi.

## Files
- `index.html` — page structure and all text
- `style.css` — visual design, responsive layout, animations
- `script.js` — countdown, reveals, hearts, buttons and optional ambient melody
- `images/` — the uploaded photos

## How to run
1. Keep `index.html`, `style.css`, `script.js`, and the `images` folder together.
2. Double-click `index.html` to open it in Chrome/Edge.
3. For the full experience, open it on a phone or resize the browser to mobile width.
4. The small ♫ button enables a gentle generated ambient melody. No music file is required.

## Personal edits
Search inside `index.html` for any sentence you want to change.
The countdown automatically targets the next October 16.
